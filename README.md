# Download Images in Element

Downloads all the images in a selected element as a ZIP. Authentication is preserved. The highest-quality image in the `srcset` is selected. No garbage UI features, no donation guilt-tripping. It even works on Android. Common sense, really, but no one's done it yet, so here you go.

![Screenshot](https://raw.githubusercontent.com/JakeHPark/Download-Images-in-Element/refs/heads/main/Screenshot.png)

There's a special-case implementation for Wikimedia. The icon is by [Pixel perfect](https://www.flaticon.com/authors/pixel-perfect).
